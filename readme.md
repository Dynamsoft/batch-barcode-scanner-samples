# Batch Barcode Scanner Samples

This repository contains multiple samples that help you integrate the [Dynamsoft Batch Barcode Scanner](https://www.dynamsoft.com/batch-barcode-scanning/overview/) mobile app into your workflow.

## Samples

### Android Samples

[Share-Receiver](./android/share-receiver/): This sample demonstrates how to create an Android app to receive scan results via sharing.

### Web Samples

[Web Viewer](./web/web-viewer/): This sample demonstrates how to view scan results uploaded to a cloud platform like OneDrive. [Online demo](https://demo.dynamsoft.com/demo-bbs-web-viewer/).
